
# Hangman Game

This command-line Hangman game is a Python project built during a coding internship to practice loops, conditionals, string manipulation, and interactive CLI input handling. In each round, a hidden word is selected and the player guesses one letter at a time within a limited number of attempts, with real-time feedback showing revealed letters, previously guessed characters, and remaining lives until the word is solved or attempts run out. To play, clone or download the repository and run `python hangman.py` in your terminal.
